# Changelog

Each public ComplyEdge package keeps its own changelog beside its code, and
versions independently. The format follows
[Keep a Changelog](https://keepachangelog.com/); versions follow
[Semantic Versioning](https://semver.org/).

| Package | Registry | Changelog |
| --- | --- | --- |
| `complyedge` (Python SDK) | [PyPI](https://pypi.org/project/complyedge/) | [sdks/python/CHANGELOG.md](sdks/python/CHANGELOG.md) |
| `@complyedge/sdk` (TypeScript SDK) | [npm](https://www.npmjs.com/package/@complyedge/sdk) | [sdks/typescript/CHANGELOG.md](sdks/typescript/CHANGELOG.md) |
| `trustlint` (offline linter) | [PyPI](https://pypi.org/project/trustlint/) and [npm](https://www.npmjs.com/package/trustlint) | [packages/trustlint/CHANGELOG.md](packages/trustlint/CHANGELOG.md) |
| `@complyedge/mcp` (MCP server) | [npm](https://www.npmjs.com/package/@complyedge/mcp) | [packages/mcp/CHANGELOG.md](packages/mcp/CHANGELOG.md) |

The rule set these packages check against lives in `rules/` and is listed,
rule by rule with the law behind each, at
[complyedge.io/rule-set](https://complyedge.io/rule-set/).
